# ماكينة الفيديوهات الفيرال 🎬

تكتب السيناريو كملف JSON، والماكينة تطلّع فيديو رأسي جاهز للنشر: ‎1080×1920‏، ‏30 fps، فيه حركة وومضات واهتزاز، وموسيقى مستمرة، ومؤثرات صوتية على كل ضربة. كل ده بالكود ومن غير أي أداة مدفوعة.

## التشغيل
```bash
node make.js scripts/01-heist.json --preview   # معاينة سريعة: صورة فيها 12 كادر
node make.js scripts/01-heist.json             # الفيديو الكامل: out/01-heist.mp4
```
المطلوب: Node وPlaywright وffmpeg وPython مع numpy.

## شكل السيناريو
```json
{ "title": "اسم الفيديو",
  "music": { "style": "action" },
  "subs": [[0, 2.5, "ترجمة اختيارية من ثانية لثانية"]],
  "scenes": [ { "type": "cctv", "dur": 2.6, "...": "..." } ] }
```
**أنواع الموسيقى** (`music.style`):
- `action`: سرعة 140، فيها بيس وطبول قوية، وضربة «براام» مع كل عنوان.
- `comedy`: سرعة 118، فيها بيز وبيتزيكاتو وصوت «بوينج».
- `trailer`: نبض قلب وصوت ممتد، وبعدين انفجار عند `drop` (بالثواني).

## أنواع المشاهد
| النوع | بيعمل إيه | أهم الخصائص |
|---|---|---|
| `cctv` | كاميرا مراقبة: REC وساعة وشريط عاجل | `tag`، و`lines[{text,at,y,size,color}]`، و`img` |
| `breaking` | خبر عاجل بشريط أخبار متحرك | `head`، و`sub`، و`ticker` |
| `slam` | عناوين بتخبط على الشاشة، أو بتنط لو حطيت `pop` | `bg`، و`rays`، و`speed`، و`lines[{text,y,size,at,color,cap,pop}]` |
| `chat` | محادثة واتساب فيها «يكتب الآن…» | `title`، و`avatar`، و`msgs[{text,me,at}]` |
| `price` | السعر القديم يتشطب والجديد ينفجر | `item`، و`emoji`، و`old`، و`new`، و`title`، و`unit` |
| `countdown` | عد تنازلي ٣، ٢، ١ | `label`، و`bg`، و`color` |
| `notif` | جوال بينزل عليه إشعار | `text`، و`cap`، و`app`، و`time` |
| `versus` | شاشة مقسومة بـ VS | `top`، و`topEmoji`، و`bot`، و`botEmoji` |
| `action` | خطوط سرعة وعنوان أكشن | `text`، و`emoji`، و`sub`، و`size`، و`bg` |
| `reaction` | إيموجي ضخم بيتهز مع تعليق، ستايل الميمز | `emoji`، و`text`، و`sub`، و`bg` |
| `photo` | صورة بحركة كاميرا بطيئة | `img`، و`bw`، و`lines` |
| `end` | شعار كيو، والدعوة للتحميل، والهاشتاج | `cta`، و`tag`، و`credit` |

- **الألوان:** `l` ليموني، و`r` أحمر، و`c` كريمي، و`k` أسود، و`w` أبيض، أو أي كود لون.
- **شكل الأفلام:** أي مشهد تحط فيه `"cinema": true` ياخد شرايط سودا فوق وتحت.

## قواعد الفيرال المطبّقة
- الهوك في أول نص ثانية، وفيه نص وحركة من أول كادر.
- المشهد بيتغيّر كل ١٫٥ لـ ٣ ثواني.
- المدة بين ٢١ و٣٤ ثانية، وده أفضل مدى لإكمال المشاهدة على تيك توك.
- الكلام المهم بعيد عن آخر ٣٢٠ بكسل تحت، لأن أزرار المنصة بتغطيها.
- الصوت على ‎-14 LUFS‏، والفيديو بمعدّل ‎8 Mbps‏ عشان المنصة ما تضغطش جودته.

بعض القواعد دي مأخوذة من دليل الفيديو القصير في مشروع OpenMontage المفتوح المصدر.
